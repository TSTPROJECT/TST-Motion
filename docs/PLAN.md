# TST Motion — แผนงาน / Plan

ชื่อ "TST Motion" เป็นชื่อชั่วคราว เปลี่ยนได้

## เป้าหมาย

โปรแกรมทำโมชั่นอนิเมชั่น 2D ฟรีและเปิดโค้ด ใช้ง่ายกว่า Live2D มาก
เป็นโปรแกรมติดตั้งบน Windows (มีไอคอนบนเดสก์ท็อป) และแอป Android ภายหลัง
รองรับภาษาไทยและอังกฤษ เครื่องสเปกต่ำก็ใช้ได้

หลักสำคัญ: **คนขยับงานเอง** AI ช่วยแค่ตัดชิ้นส่วน ไม่สร้างภาพ ไม่ขยับแทน
และปิด AI ได้ทั้งหมด เพราะมีเครื่องมือตัดด้วยมือให้ด้วย

## ความต้องการที่เลือกไว้ (10 พ.ย. 2026)

| เรื่อง | ที่เลือก |
|---|---|
| ลักษณะงาน | Motion graphic และตัวละคร 2D แบบตัดชิ้น |
| ใช้กับ | TikTok / Reels (9:16), YouTube (16:9) |
| รูปที่ใช้ | ภาพวาดการ์ตูนเป็นหลัก |
| ตัดชิ้นอัตโนมัติ | ลบพื้นหลัง, แยกหลายวัตถุเป็นเลเยอร์, แยกหัว ตัว แขน ขา มือ, เส้นผม (หน้าม้า ผมหลัง หางม้า), ใบหน้า (ตา ปาก), เสื้อผ้า, สิ่งของที่ถือ; เลือกความละเอียด หยาบ/ปกติ/ละเอียด และเลือกหมวดที่จะแยกได้ |
| หน้าตา | ทันสมัย แผงลอยมุมมน ผืนงานลายจุด แถบเครื่องมือลอย ธีมมืด/สว่าง มือถือใช้แท็บ ไทม์ไลน์/เลเยอร์/คุณสมบัติ; มือถือแนวนอน: ภาพซ้าย แผงแท็บขวา |
| ฟีเจอร์เวอร์ชันแรก | ไทม์ไลน์ + คีย์เฟรม, กระดูก/ข้อต่อ, ดัดรูปโค้งงอ |
| นำเข้า | รูปหลายสกุล: PNG, JPG, WebP, SVG, GIF, BMP, AVIF, PSD (แยกเลเยอร์) |
| ส่งออก | MP4 (พื้นเขียว/สีที่เลือก), WebM พื้นใส, MOV พื้นใส, GIF |
| การเรนเดอร์ | ติ๊กได้หลายชนิดไฟล์ แล้วเรนเดอร์ทีเดียว |
| ความละเอียด / ความยาว | สูงสุด 4K / สูงสุด 105 วินาที |
| เครื่องต่ำสุด | โน้ตบุ๊ก RAM 4GB ไม่มีการ์ดจอแยก, Android ราคาประหยัด (iPhone/iPad พักไว้ก่อน: ต้องใช้เครื่อง Mac และค่าสมาชิก Apple) |
| บันทึกงาน | ในเครื่อง + ไฟล์โปรเจกต์ ไม่มีล็อกอิน ไม่มีคลาวด์ |
| แจกจ่าย | ฟรี เปิดโค้ด ไม่มีลายน้ำ มีปุ่มบริจาคเล็กๆ |

## วิธีสร้าง

- **โปรแกรมติดตั้ง ไม่ใช่เว็บ** (เปลี่ยนเมื่อ 11 พ.ย. 2026): ใช้ Tauri ห่อหน้าจอแก้ไขเป็นโปรแกรม Windows
  ตัวติดตั้งเล็ก (ราว 10 MB) ใช้ RAM น้อย ใช้ตัวแสดงผล WebView2 ที่มากับ Windows อยู่แล้ว ไม่ต้องต่อเน็ต
- ตัวติดตั้งแบบ NSIS ลงเฉพาะผู้ใช้ ไม่ต้องสิทธิ์แอดมิน มีไอคอนบนเดสก์ท็อปและเมนู Start
  ดับเบิลคลิกไฟล์ .tstm แล้วเปิดในโปรแกรมได้เลย
- Android: สร้าง .apk จากโค้ดชุดเดียวกันด้วย Tauri ภายหลัง (ต้องลง Android Studio เพิ่ม)
- วาดภาพด้วย WebGL (การ์ดจอในตัวของโน้ตบุ๊กทั่วไปก็ใช้ได้)
- ส่งออกวิดีโอด้วยตัวเข้ารหัสในเบราว์เซอร์ (WebCodecs) เรนเดอร์ทีละเฟรมแล้วเขียนลงไฟล์เลย ไม่กิน RAM
- MOV พื้นใสเขียนเองในรูปแบบที่ Premiere, After Effects และ DaVinci เปิดได้ ไม่ต้องใช้ ffmpeg ที่หนัก
- AI ตัดชิ้นส่วนทำงานในเครื่อง ดาวน์โหลดโมเดลเล็กครั้งเดียวตอนใช้ครั้งแรก รูปไม่ถูกส่งออกไปไหน
- ตอนตัดต่อแสดงตัวอย่างที่ความละเอียดต่ำลงอัตโนมัติบนเครื่องอ่อน แต่ไฟล์ที่ส่งออกเต็มความละเอียด
- ภาษาไทย/อังกฤษสลับได้ตลอด ใช้ภาษาของเครื่องเป็นค่าเริ่มต้น
- โค้ดเปิดด้วยสัญญาอนุญาต MIT

## ข้อจำกัดที่รู้แล้ว

- MP4 เก็บพื้นใสไม่ได้ จึงใช้พื้นเขียวหรือสีที่เลือก
- GIF ทำพื้นใสได้แต่ขอบไม่เนียน (ใสหรือไม่ใสเท่านั้น ไม่มีโปร่งครึ่งๆ)
- การแยกหัว แขน ขาจากภาพการ์ตูนแบบอัตโนมัติล้วนยังไม่แม่นพอ
  จึงให้ระบบเดาให้ก่อน แล้วแตะหนึ่งครั้งต่อชิ้นเพื่อแก้ และมีแปรงเก็บขอบ
- ส่วนที่ถูกบัง (เช่น ลำตัวใต้แขน) จะเป็นรูโหว่ ต้องวาดเติมเอง ตามที่เลือกว่าไม่ใช้ AI เติม
- 4K บนเครื่อง RAM 4GB เรนเดอร์ได้แต่ช้า
- ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล Windows อาจขึ้นเตือน "Windows protected your PC" ต้องกด More info > Run anyway

## เฟส

0. **หน้าตาตัวอย่าง** ให้กดลองบนคอมและมือถือ เพื่อตกลงหน้าตาก่อนเขียนจริง
1. **ตัวแก้ไขหลัก**: นำเข้ารูปหลายสกุล, เลเยอร์, ย้าย หมุน ย่อขยาย, ไทม์ไลน์ + คีย์เฟรม,
   การเคลื่อนที่แบบนุ่มนวล, บันทึก/เปิดไฟล์โปรเจกต์, ไทย/อังกฤษ, ใช้นิ้วได้, โปรแกรมติดตั้ง Windows
2. **ส่งออก**: MP4, WebM พื้นใส, MOV พื้นใส, GIF, เลือกหลายชนิดแล้วเรนเดอร์ทีเดียว, 9:16 / 16:9 / 1:1, สูงสุด 4K
3. **ตัดชิ้นส่วน**: เครื่องมือตัดด้วยมือ (บ่วงบาศ แปรง ยางลบ), ลบพื้นหลัง, แยกวัตถุเป็นเลเยอร์,
   แยกหัว ตัว แขน ขา (ระบบเดาแล้วแตะแก้)
4. **กระดูกและดัดรูป**: ข้อต่อแม่-ลูก, จุดหมุน, ดึงปลายแขนแล้วข้อศอกตาม (IK), ตาข่ายดัดรูปให้โค้งงอตามกระดูก
5. **แอป Android** สร้าง .apk จากโค้ดเดียวกัน
6. **ภายหลัง**: ข้อความ + ฟอนต์ไทย, ท่าสำเร็จรูป, เพลง/เสียง, กล้อง, เอฟเฟกต์, ปากขยับตามเสียง
