# TST Motion — แผนงาน / Plan

ชื่อ "TST Motion" เป็นชื่อชั่วคราว เปลี่ยนได้

## เป้าหมาย

โปรแกรมทำโมชั่นอนิเมชั่น 2D ฟรีและเปิดโค้ด ใช้ง่ายกว่า Live2D มาก
เป็นโปรแกรมติดตั้งบน Windows (มีไอคอนบนเดสก์ท็อป) และแอป Android ภายหลัง
รองรับภาษาไทยและอังกฤษ เครื่องสเปกต่ำก็ใช้ได้

หลักสำคัญ: **คนขยับงานเอง** AI ช่วยแค่ตัดชิ้นส่วน ไม่สร้างภาพ ไม่ขยับแทน
และปิด AI ได้ทั้งหมด เพราะมีเครื่องมือตัดด้วยมือให้ด้วย

## ความต้องการที่เลือกไว้ (10 พ.ย. 2026)

| ฟีเจอร์เวอร์ชันแรก | ไทม์ไลน์ + คีย์เฟรม, กระดูก/ข้อต่อ, ดัดรูปโค้งงอ |

| ส่งออก | MP4 (พื้นเขียว/สีที่เลือก), WebM พื้นใส, MOV พื้นใส, GIF |

## วิธีสร้าง

- **โปรแกรมติดตั้ง ไม่ใช่เว็บ** (เปลี่ยนเมื่อ 11 พ.ย. 2026): ใช้ Tauri ห่อหน้าจอแก้ไขเป็นโปรแกรม Windows
  ตัวติดตั้งเล็ก (ราว 10 MB) ใช้ RAM น้อย ใช้ตัวแสดงผล WebView2 ที่มากับ Windows อยู่แล้ว ไม่ต้องต่อเน็ต
- ตัวติดตั้งแบบ NSIS ลงเฉพาะผู้ใช้ ไม่ต้องสิทธิ์แอดมิน มีไอคอนบนเดสก์ท็อปและเมนู Start
  ดับเบิลคลิกไฟล์ .tstm แล้วเปิดในโปรแกรมได้เลย
- Android: สร้าง .apk จากโค้ดชุดเดียวกันด้วย Tauri ภายหลัง (ต้องลง Android Studio เพิ่ม)
- วาดภาพด้วย WebGL (การ์ดจอในตัวของโน้ตบุ๊กทั่วไปก็ใช้ได้)
- ส่งออกวิดีโอด้วยตัวเข้ารหัสที่มากับ WebView2 (WebCodecs, ใช้การ์ดจอช่วยถ้ามี) ผ่านไลบรารี Mediabunny
  เรนเดอร์ทีละเฟรมแล้วเขียนลงไฟล์เลย ไม่กิน RAM (ทดสอบ 4K ใช้หน่วยความจำราว 60 MB)
- MP4 = H.264, WebM พื้นใส = VP9 + ช่องใสแยก (แบบเดียวกับที่ Chrome/ffmpeg ทำ), GIF = gifenc
- MOV พื้นใส = เฟรม PNG ในไฟล์ QuickTime เขียนเอง (ไม่สูญเสียคุณภาพ เปิดใน After Effects / Premiere ได้)
  ยังไม่ใช่ ProRes 4444 เพราะไม่มีตัวเข้ารหัสในเบราว์เซอร์ ถ้าต้องการ ProRes ต้องรวม ffmpeg ทำให้ตัวติดตั้งใหญ่ขึ้นราว 30 MB
- AI ตัดชิ้นส่วนทำงานในเครื่อง ฟรี ไม่ต้องใช้บริการที่เสียเงิน ดาวน์โหลดโมเดลครั้งเดียวตอนใช้ครั้งแรก
  (ตรวจขนาดและลายนิ้วมือไฟล์ทุกครั้ง) รูปไม่ถูกส่งออกไปไหน
  - แตะเลือกด้วย AI: SlimSAM-77 (Apache-2.0) ราว 14 MB
  - แยกหัว แขน ขา อัตโนมัติ: ViTPose base 4 บิต (Apache-2.0) ราว 57 MB หาข้อต่อ แล้วใช้ SlimSAM หาขอบแต่ละชิ้น
  - รันบน CPU ด้วย onnxruntime-web ในเธรดแยก หน้าจอไม่ค้างระหว่างคิด
- ตอนตัดต่อแสดงตัวอย่างที่ความละเอียดต่ำลงอัตโนมัติบนเครื่องอ่อน แต่ไฟล์ที่ส่งออกเต็มความละเอียด
- ภาษาไทย/อังกฤษสลับได้ตลอด ใช้ภาษาของเครื่องเป็นค่าเริ่มต้น
- โค้ดเปิดด้วยสัญญาอนุญาต MIT

## ข้อจำกัดที่รู้แล้ว

- MP4 เก็บพื้นใสไม่ได้ จึงใช้พื้นเขียวหรือสีที่เลือก
- GIF ทำพื้นใสได้แต่ขอบไม่เนียน (ใสหรือไม่ใสเท่านั้น ไม่มีโปร่งครึ่งๆ)
- การแยกหัว แขน ขาจากภาพการ์ตูนแบบอัตโนมัติล้วนยังไม่แม่นพอ
  จึงให้ระบบเดาให้ก่อน แล้วแตะหนึ่งครั้งต่อชิ้นเพื่อแก้ และมีแปรงเก็บขอบ
- ส่วนที่ถูกบัง (เช่น ลำตัวใต้แขน) ไม่มีภาพจริง ตามที่เลือกว่าไม่ใช้ AI เติม
  ตอนแยกชิ้นอัตโนมัติจะใส่ส่วนเกยตรงข้อต่อให้ หมุนได้ราว 45° โดยไม่เห็นรู ถ้าหมุนมากกว่านั้นต้องวาดเติมเอง
- แยกชิ้นอัตโนมัติ: ขาในกระโปรงหรือเสื้อคลุมยาวมองไม่เห็น ระบบแบ่งตามตำแหน่งเข่าที่เดา อาจต้องแตะแก้
  รูปพื้นทึบจะตัดพื้นสีเรียบรอบตัวละครให้เอง พื้นลายหรือภาพถ่ายอาจตัดไม่หมด ให้ "ลบพื้นหลัง" หรือตัดเองก่อน
- เดาชิ้นส่วนครั้งแรกของรูปใหม่ใช้ราว 20–40 วินาที (AI ต้องดูรูปก่อน) เดาใหม่ในรูปเดิมราว 4 วินาที
- 4K บนเครื่อง RAM 4GB เรนเดอร์ได้แต่ช้า; MOV ที่ 4K ช้าที่สุดเพราะต้องบีบอัด PNG ทุกเฟรม
- รูปใหญ่: รับได้ถึง 16000 พิกเซลต่อด้าน / 160 ล้านพิกเซล ใหญ่กว่านั้นจะย่อลงพอดีตอนนำเข้า (แจ้งให้รู้)
  ตอนตัดชิ้น รูปที่ใหญ่กว่า ~24 ล้านพิกเซล (RAM 8GB; 16 ล้านที่ 4GB) จะใช้สำเนาย่อในหน้าต่างตัด แล้วตัดชิ้นจริงจากรูปเต็ม
  ขอบชิ้นจึงนุ่มกว่าการตัดทีละพิกเซลเล็กน้อย; ตัด/ลบพื้นหลังรูป 50 ล้านพิกเซลใช้ราว 7–9 วินาที (บีบอัด PNG รูปเต็ม)
- รูปที่พื้นหลังไล่สีหรือมีเงาบนพื้น "ลบพื้นหลัง" อาจไม่หมด ให้ใช้ไฟล์พื้นใสถ้ามี
- MOV แบบ PNG ไฟล์ใหญ่ และ DaVinci Resolve บางรุ่นอาจเปิดไม่ได้ (ยังไม่ได้ทดสอบ) ถ้าใช้ DaVinci ให้ลองก่อน
- หมุดดัด หันหน้า 3D และข้อต่อนุ่มต้องใช้ WebGL ถ้าเครื่องไม่มี WebGL จะวาดแบบไม่โค้ง (ภาพยังขยับได้)
- ท่าสำเร็จรูปหาชิ้นจากชื่อ (หัว ตัว ตา แขนขวา) ถ้าตั้งชื่ออื่นจะใช้ชิ้นที่เลือกแทน
- กลับข้างท่าสลับเฉพาะการหมุน ตำแหน่งชิ้นไม่สลับ
- แยกชิ้นสัตว์/สิ่งของตามรูปทรง (ไม่ใช้ AI): แบ่งตรงคอคอดของรูป ตั้งชื่อตามตำแหน่งที่ติดตัว (ขา ส่วนบน ส่วนข้าง)
  ไม่รู้ว่าชิ้นไหนคือหัวหรือหาง ขาที่ชิดกันหรือหางที่แนบตัวอาจรวมเป็นชิ้นเดียว ต้องแตะแก้
- ไทม์แลปส์ถ่ายเฉพาะหน้าต่างโปรแกรม TST Motion (ไม่ใช่ทั้งจอ) ทุก 2 วินาทีเฉพาะตอนมีการทำงาน; เก็บในเครื่องจนกว่าจะลบ
- ปากขยับตามเสียงใช้ความดัง ไม่ได้ดูสระ จึงได้ปากเปิด-ปิดตามจังหวะ ไม่ใช่รูปปากตามคำ
- ภาพที่มีพื้นหลังเป็นฉาก (ไม่ใช่สีเรียบ) ต้องตัดตัวละครออกก่อน ไม่อย่างนั้น AI จะแบ่งฉากรวมไปด้วย
- ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล Windows อาจขึ้นเตือน "Windows protected your PC" ต้องกด More info > Run anyway

   การเคลื่อนที่แบบนุ่มนวล, บันทึก/เปิดไฟล์โปรเจกต์, ไทย/อังกฤษ, ใช้นิ้วได้, โปรแกรมติดตั้ง Windows
2. **ส่งออก** ✅ (11 พ.ย. 2026): MP4 (สีพื้นหลังเลือกได้), WebM พื้นใส, MOV พื้นใส (PNG), GIF (พื้นใสได้),
   ติ๊กหลายชนิดแล้วเรนเดอร์ทีเดียว, ขนาด HD ถึง 4K ตามรูปทรงงาน, แถบความคืบหน้า + เวลาที่เหลือ + ยกเลิกได้
3. **ตัดชิ้นส่วน** ✅ (11 พ.ย. 2026): เครื่องมือตัดด้วยมือ (ไม้กายสิทธิ์ บ่วงบาศ แปรง ยางลบ), แตะเลือกด้วย AI,
   ลบพื้นหลัง, แยกวัตถุที่ไม่ติดกันเป็นเลเยอร์, แยกหัว ตัว แขน ขา อัตโนมัติ 3 ระดับ (หยาบ 6 / ปกติ 10 / ละเอียด 13 ชิ้น)
   ระบบเดาแล้วแตะหรือระบายแก้ ได้เลเยอร์ที่มีจุดหมุนที่ข้อต่อ ชิ้นลูกตามชิ้นแม่ เรียงหน้าหลัง และเกยกันที่ข้อต่อ
4. **กระดูกและดัดรูป** ✅ (13 พ.ย. 2026): ข้อต่อแม่-ลูก, จุดหมุน, เครื่องมือจัดท่า (ดึงปลายแขนแล้วข้อศอกตาม IK),
   ข้อต่อนุ่ม (ภาพโค้งงอที่ข้อต่อ)
4.5 **ละเอียดแบบ AE / Live2D แต่ใช้ง่าย** ✅ (13 พ.ย. 2026, 0.5.0–0.5.5):
   สวิตช์โหมดง่าย/ขั้นสูง (ขั้นสูงแสดงตัวเลขละเอียด), หมุดดัดรูป (ปักหมุดแล้วลากให้ภาพโค้ง ใส่คีย์ได้),
   ตัดเองแบบละเอียด (บ่วงบาศคลิกทีละจุด + แม่เหล็กเกาะขอบ, ตารางพิกเซล, ขยาย/หด/เกลาขอบ, ดูเฉพาะที่เลือก),
   สลับภาพ ตา/ปาก, ผม/ผ้าพลิ้วเอง (จำลองสปริงทั้งคลิป), หันหน้าแบบ 3D (หน้าโค้งแบบลูกบอล ชิ้นบนหน้าเลื่อนตามความลึก),
   กราฟความเร็วต่อคีย์, เห็นเฟรมข้างเคียง, คลังท่า + ก็อป/วาง/กลับข้างท่า + วนลูปเนียน,
   ท่าสำเร็จรูปกดเดียว (หายใจ กระพริบตา พยักหน้า ส่ายหน้า โบกมือ เด้งดึ๋ง โยกตัว)
